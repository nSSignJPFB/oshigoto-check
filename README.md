# n.SSign Daily Support Tracker

GitHub Pagesにそのままアップロードして使える、n.SSign応援用TODOチェックリストです。

## 機能
- 日付の自動表示
- 同日内のチェック維持
- 日付が変わった時だけ自動リセット
- 各アプリの画像表示
- 今日の達成率表示
- 全チェックで「コンプリート🎉」
- スマホホーム画面追加対応（PWA）

## 使い方
1. このフォルダの中身をGitHubリポジトリにアップロード
2. GitHubの Settings → Pages
3. Branchを `main`、Folderを `/root` にして保存
4. 表示されたURLにアクセス

## アプリ画像を公式画像に差し替える場合
`assets`フォルダ内の以下ファイルを、同じファイル名で上書きしてください。

- mubeat.svg
- higher.svg
- duckad.svg
- idolchamp.svg
- starplanet.svg
- mnetplus.svg

公式ロゴ・アプリアイコンを使用する場合は、各サービスの利用規約・権利表記に注意してください。
